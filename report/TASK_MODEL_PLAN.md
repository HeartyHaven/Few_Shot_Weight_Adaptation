# 任务与模型方案（主实验 + 三组分析）

2026-11-20，main@ws006343。依据：项目文档《GPT-Guided Model Editing》、本仓库已有结果（`pilot/BL_LORA.md`、网页“对照组”标签）、公开文献，以及一次 200 题级别的难度摸底（`pilot/scripts/hardtask_pilot.py`，vLLM bf16，非思考模式，零样本）。

## 1. 选任务的标准

1. **有公开训练集**，可以做 LoRA / 全量数据对照（B2、B4）。
2. **训练完仍然做不好**：文献里用训练集微调后离满分还远。
3. **背后有一套可讲清楚的流程**（规则、公式、执行步骤），而不是靠记大量事实。我们的已有结果说明：瓶颈是“不知道规则”时，提示和提示烘焙最强（Qwen3 4B MedCalc 规则题：提示 71.9%，烘焙 71.6%，教师编辑 55.6%）；瓶颈是“执行出错”时，提示无效甚至有害（Gemma 1B 物体追踪：提示后 57.7% → 23.3%），这才是教师编辑最有价值的地方。新任务应偏向“执行难”。
4. **能自动精确评分**，且 1.7B–14B 学生起点在 20%–60%，不在地板也不在天花板。

## 2. 推荐的主表任务

| 位置 | 任务 | 数据与划分 | 评分 | 起点（未编辑，摸底） | 训练后仍做不好的证据 |
|---|---|---|---|---|---|
| 通用（简单） | **物体交换追踪**（BBH tracking_shuffled_objects，已在做） | 生成器出题；隐藏测试 = BBH 原题 750 + 新题 300 + 更难 150 | 选项完全匹配；主指标 BBH 原题 | Gemma 1B 56.9%，Qwen 1.7B 58.7% | 不需要：这是“简单任务”，LoRA 能到 99% |
| 医疗 | **MedCalc-Bench Verified，规则类 + 公式类** | 训练集 10,538；测试 1,100（19 种规则类 380 题已在用；再加公式类 lab/physical/dosage 计算器）。每类选 8 种“教过的”，其余作连带影响 | 规则类：分数完全相等；公式类：落在数据集给的上下限内（官方 ±5%）。主指标：教过的计算器正确率 | 规则类教过的：Qwen 1.7B 21.9%，4B 26.9%；公式类：Qwen 1.7B 24.0%，4B 50.5%，Gemma 4B 26.5% | 原论文 SFT：Mistral-7B 49.2%、Llama-2-7B 45.8%；RL 最好约 74%。本仓库 Qwen3 4B 全量 LoRA 60.6% |
| 数学 | **MATH Level 5**（数论 + 计数与概率 + 中级代数 + 微积分前），可先只用数论 + 计数概率两科 | 训练 = MATH train 同科目（数论 869 题、计数概率 771 题，含 L1–5 带完整解答）；测试 = 同科目 L5（数论 154、计数概率 123） | 最终答案等价：先取最后一个 “Final answer” 或 `\boxed{}`，用 math-verify（sympy 等价）判对；报告整体和分科 | 4 科平均：Qwen 1.7B 32%，4B 49%，Gemma 4B 32%（数论/计数约 50–64%，代数/微积分前 10–36%） | 小模型在 L4–5 上 SFT 收益很小甚至为负；SFT 在难题上约 65% 处饱和 |
| 代码 | **CRUXEval-O**（给函数和输入，预测输出） | 测试 800 题（官方，无训练集）；训练集按原论文做法生成：采样短 Python 函数 + 输入，**真实执行**得到输出，去重后约 1 万条 | 预测值与真实输出按 Python 字面量相等（`ast.literal_eval` 比较）；取最后一个 “Final answer” 之后的内容 | Qwen 1.7B 59%，4B 66.5%，Gemma 4B 50% | 原论文用 14 万条训练 Code Llama 34B 后仍“离完美很远”（GPT-4 CoT 81%） |

说明：
- **医疗**是目前最成熟的一项，继续用。只用规则类时，4B 学生的瓶颈主要是“记不住规则”（提示即可到 72%），对教师不利；加入公式类（要做单位换算、代公式、算术）后更偏“执行难”。
- **数学**选 L5 而不是 L1–3：我们摸底里 L1–3 数论 Qwen 1.7B 已 75%、27B 84.7%，太容易。
- **代码**不用 MBPP：Gemma 27B 84.7%，太容易；也不用 APPS：需要算法知识，不是“可讲清楚的流程”，而且小模型接近 0%。CRUXEval-O 是“逐行模拟执行”，最接近物体追踪那种可教的执行过程，训练数据可以无限生成并且答案由真实执行保证正确。
- **放弃 DDXPlus**：Qwen 1.7B 已 66.8%，27B 71.5%，且主要靠疾病知识而不是流程。

## 5. 评分与对照的统一规定

- **数据划分**（与已有 T1/T2 相同）：教师可见 100 道带答案的真题（另可自编至多 300 道）；隐藏验证 120–150 道（每次运行最多看 10 次分数）；隐藏测试为表中所列，教师从未见过。
- **主指标**：各任务隐藏测试正确率（定义见第 2 节），报告 bootstrap 95% 置信区间；每个（学生、任务）教 3 次取均值和标准差（文档要求）。
- **副作用（主表“平均副作用”一列）**：编辑前后的平均变化，取以下各项的均值：
  - 通用文本困惑度（上升不超过 10%）；
  - ARC-Challenge 300 题、HellaSwag 300 题（强制选择）；
  - MMLU 1,140 题（57 科各 20 题）、GSM8K 500 题（`tdwa/retention_vllm.py`）；
  - 可选 IFEval（需官方检查器，尚未接入）。
- **对照组**：B0 未编辑、B1 提示（流程或规则写在题前）、B2 LoRA 只用同样 100 道真题、B4 LoRA 用全部训练集、B5 提示烘焙。主表的 “Prompt” 用 B1，“Lora” 建议同时给 B2（同数据）和 B4（数据充足的上限）。
