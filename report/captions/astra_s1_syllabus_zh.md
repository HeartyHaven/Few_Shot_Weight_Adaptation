# 物品状态追踪教学大纲
1. 读懂初始的一一对应：每个有名字的人恰好拿着一样东西。检查能否直接查出某人最初拿的是什么。
2. 同时执行一次交换：对调的是两人当前手里的东西，不是最初的东西。用一次交换和重复交换的例子来检查。
3. 按时间顺序把多次交换连起来做；没参与的人保持不变。每一步之后检查完整的状态表。
4. 另一种做法是从被问到的人倒着追：从被问的人出发，从最后一次交换往前扫，只要当前名字参与了交换，就换成对方的名字；最后查这个名字最初拿的东西。检查倒推出的持有人链条。
5. 把得到的物品对到列出的选项上，给出一个不含糊的最终答案。把“查出物品”和“对到选项”分开检查。
6. 在正式题面不给任何提示的情况下，推广到不同的人名、物品、措辞和序列长度。

诊断代码：E1 不知道规则；E2 知道规则但执行不好；E3 缺某个子技能；E4 答案格式问题；E5 其他。
