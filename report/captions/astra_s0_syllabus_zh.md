# 物品状态追踪教学大纲

1. 读懂初始的一一对应关系：每个人对应一样东西（包括舞伴、场上位置和其他角色）。
2. 一次交换是把两人**当前**持有的东西同时对调；其他人手里的东西都不变。
3. 按题目给出的顺序执行交换，始终保留完整的对应关系。同一对人重复交换，两两抵消。
4. 另一种省事的方法：从被问到的那个人出发，倒着扫描交换记录。只要当前名字是某次交换的一方，就把它换成另一方。最后拿得到的名字去**初始**对应关系里查。
5. 把最终的物品和选项对上，用选项字母作答。

检查项：初始查找；一次交换；无关的交换；重复交换抵消；多次相互影响的交换；正推与倒推结果一致；没见过的措辞和更长的序列；选项格式。把普通的正式题面和带明确解法说明的题面做对比。区分 E1 不知道规则、E2 知道但执行不好、E3 缺某个子技能、E4 答案格式问题、E5 其他问题。

权重编辑的效果必须能迁移到普通的正式题面上，不能依赖外部求解器，也不能依赖改动过的推理流程。副作用用通用困惑度和副作用检查题来检查。

## 最终观察到的掌握情况
- 嘴上会说交换规则，不等于能执行：两次交换有时被当成只做一次（做一次和做两次结果一样）。
- 模型里存在一条专门的“第17层0号头”抄写回路，在喂入正确解题过程逐点检查时表现很强。适度放大它，再配合减弱两个中间层的注意力头，能小幅提高正式成绩。
- “从最终状态查出物品”和“把物品对到选项”仍然是两个各自独立的出错点。
- 倒推法和紧凑表格法的说明，学生都不能可靠地照做；示例有时还会污染真实的状态。
- 更长的序列会让学生编造出多余的交换，写出没完没了的状态表；把生成长度放宽到2048个词元，也没能修好观察到的5条被截断的作答。
- 普通题面下的隐藏验证从53.33%提高到57.33%；这算不上可靠地掌握了任务。向9人题的迁移没有得到证明。
