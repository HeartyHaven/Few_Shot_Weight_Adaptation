# 教学大纲：物体状态追踪（交换类题目）

## 要教的解题步骤

1. **列初始表**：按题目给出的顺序，每人写一行：`姓名: 物品`。
2. **按顺序处理每一次交换**“X 和 Y 交换”：
   - a. **查找**：在最近一张表里找到 X 的行和 Y 的行。
   - b. **交换**：X 的新物品 = Y 原来的物品；Y 的新物品 = X 原来的物品。
   - c. **照抄**：其余每一行从最近一张表原样抄下来。写出完整的新表。
   - （不变量：每张表都是初始物品的一个排列，不重复、不丢失。）
3. **读结果**：只看最后一张表，找到被问的那个人的行，说出那件物品。
4. **选字母**：在选项列表里找到这件物品，输出它的字母，格式为 `Final answer: (X)`。

## 子技能和检查办法

| 编号 | 子技能 | 怎么检查 |
|----|-----------|-------|
| S0 | 知道规则，会选择写表格过程 | 看自由作答：有没有写初始表和每次交换一张表 |
| S1 | 从题目正确抄出初始表 | 解析出的第一张表是否等于标准答案 |
| S2 | 照抄不参与交换的行 | 每一步：不在交换里的行是否等于学生自己的上一张表 |
| S3 | 查找并交换两行 | 每一步：交换的两行是否等于上一张表里对调后的结果 |
| S4 | 不跳步、不重复步骤 | 表的数量是否等于交换次数 + 1 |
| S5 | 从最后一张表读出被问者那一行 | 说出的物品是否等于最后一张表里被问者的物品 |
| S6 | 物品对应到选项字母 | 字母对应的物品是否等于说出的物品 |
| S7 | 答案格式 | 是否有 `Final answer: (X)` |

检查有两种方式：（一）解析学生自由作答里写的过程；（二）把标准过程按学生自己的书写格式喂给它，在每个需要做决定的位置测它写出正确 token 的概率（密集、便宜）。

## 教学结束后的掌握情况（保留编辑 1 和编辑 2）

| 编号 | 子技能 | 教学前 | 教学后 | 怎么测的 |
|----|-----------|--------|-------|--------------|
| S0 | 写表格过程 | 合格 | 合格 | 100/100 份真题答卷 |
| S1 | 初始表 | 1.00 | 1.00 | 真题，喂标准过程逐点检查 |
| S2 | 照抄不参与交换的行 | 0.994 | 0.997 | 同上 |
| S3 | 查找并交换两行（首个 token） | 0.943 | 0.979 | 同上；自由作答的步骤错误从 67 降到 45（共约 535 步） |
| S3' | 交换行里多词物品名的后续 token | 未测 | 0.975 | 同上；自由作答里有 21 行被写乱，**没有修好**（编辑 3 已撤回） |
| S4 | 按顺序执行交换，每次一遍，然后停 | 真题 96% 全对；长题 36/76 全对 | 真题 95%；长题 48/76 | 自由作答里的步骤标题序列 |
| S5 | 从最后一张表读出被问者那一行 | 0.68 | 0.92–0.94 | 喂标准过程逐点检查；真题里读错行的从 16 道降到 5 道 |
| S6 | 说出的物品对应的字母 | 0.85 一致 | 0.85 | 自由作答文本；**没有教**（文本超过 512 token 的局部窗口时为 0.77） |
| S7 | 答案格式 | 合格 | 合格 | 没有最终答案的比例 0–1% |

教学顺序：（单元 1）S5 + S3 按行查找；（单元 2）S4 按列表顺序。针对 S6 和 S3' 的单元尝试过，已撤回。
