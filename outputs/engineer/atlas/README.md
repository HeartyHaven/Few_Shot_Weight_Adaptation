# 编辑图谱子页面交接

交付文件是 atlas.html，一个自包含 HTML（内联 CSS / JS，无依赖、无 CDN、无模型调用）。main 可按原指派复制为 report/atlas.html；页面读取其相对目录的 site/atlas.json 和 site/atlas_roles.json。返回链接固定为 index.html。

实现了任务与学生筛选、最终保留开关、可点击部位网格、逐步时间线及验证曲线、共性表、重复高改动神经元表和跨学生相对深度分布。兼容浅色 / 深色外观，表格与图使用各自的滚动容器。

## 统计口径

- q/o 按查询头编号，k/v 按 KV 头编号。网格中共享 KV 显示到关联查询头格子里，并明确标注共享关系；点击详情显示实际改动的投影。共性表按实际部件去重，不把共享 KV 重复计为多个查询头。
- 同一部件同一运行内多次编辑只计一次运行；教师计数独立去重。最终保留筛选只由 kept_final 决定，取消后包含撤回和被拒的尝试。
- 中文定位解释与实际编辑是两种证据：定位条目不会被当作真实改动。整层探测不被扩张到每个头。没有关联编辑编号的说明只作为定位资料。
- MLP 网格统计神经元编号的并集。列表不足以求精确并集时显示上下界；共性神经元表只统计数据中给出的高改动单元，按层、模块、编号和运行去重。
- 单元柱长是范数比，不是可加和的概率。相对深度以每个编辑涉及的每层计一次，按层号 / 层数分十箱，显示该学生内的比例。
- 验证曲线按考试次序画，避免回滚后旧编辑编号造成时间倒流。首次和末次验证不冒充最终测试或最终权重分数。
- 所有外部文本转义后显示。中文说明文件缺失、部分运行缺失说明、空数据、读取失败均有页面提示和重试入口。

## 已执行的验证

在项目根目录执行：

    node outputs/engineer/atlas/check_atlas.js

结果写入 checks.json。本轮通过 29 项检查，包括两组指定真实数据的聚合和页面渲染 / 筛选事件、共享 KV、去重、top-24 截断、神经元计数边界、探测历史、缺失文件和文本转义。真实 atlas_roles.json 已生成；也已检查其 20 次运行的摘要、时间线和部位关联，在两种编辑筛选下均能渲染。

检查脚本在内存中造了两条中文角色说明验证关联逻辑，没有写出假 JSON，没有在交付 atlas.html 中嵌入测试说明。页面不包含测试数据回退逻辑。脚本的最小 DOM 替身不等同于浏览器，不覆盖 CSS 布局。

## 浏览器验收尚待 main 完成

本会话运行 python -m http.server 8879 --bind 127.0.0.1 --directory report，在创建 socket 时得到 PermissionError: [Errno 1] Operation not permitted。因此未完成要求的 HTTP 浏览器验收，不能声称控制台与手机布局已通过。

在可创建本地服务的环境中，从项目根目录执行下面的命令。软链接只在本角色目录内创建，目标数据只读；若 site 已存在，保留它并先检查指向，不要覆盖。

    ln -s ../../../report/site outputs/engineer/atlas/site
    python3 -m http.server 8879 --bind 127.0.0.1 --directory outputs/engineer/atlas

然后打开：

- http://127.0.0.1:8879/atlas.html ：真实页面。
- http://127.0.0.1:8879/browser_check.html ：自动运行两组数据、筛选、点击、原文展开、主题、桌面与手机宽度检查，显示 PASS / FAIL。

后者只加载交付页面原文和真实相对路径数据，并注入错误收集代码；不修改交付页面。还需人工看一遍网格与颜色，在开发者工具 Network / Console 确认数据请求成功。若 atlas_roles.json 尚未生成，其请求缺失会有提示；完整验收应在真实说明文件到位后进行。

browser_check.html、check_atlas.js、checks.json 和本交接文件无需复制到主报告。看板的完成标记与复制 / 发布由现有 atlas-page 的 main 接收流程处理，本角色没有修改看板或主报告。
